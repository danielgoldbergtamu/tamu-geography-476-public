GEOG 476 · GIS Practicum

Texas A&M University, Department of Geography — the course pages

A writing-intensive GIS capstone rebuilt so that AI use is required rather than permitted, and so that what is graded is the student's judgment about AI output rather than whether they used it.

Every page below is standalone HTML with its styling inline — no build step, no JavaScript, no images. Open one in a browser, or paste its source into a Canvas page and it arrives intact. Take a page, an assignment, or a single rubric criterion; none of it depends on the rest.

Where to start

AI Usage in this Class is the reasoning behind everything else, and the page every assignment links back to. The Ethics Essay is one assignment end to end, and the rubrics show how AI use is actually graded.

To take a copy: use the green Code button on the repository and choose Download ZIP, or clone it. Everything is plain files.
